# .github · ATC-Real Simulation

Dépôt de configuration de l'organisation GitHub **ATC-REAL-SIMULATION**.

Il contient :

| Fichier | Rôle |
|---|---|
| [profile/README.md](profile/README.md) | Page de profil de l'organisation (histoire, éditions, partenaires, dons) |
| [FUNDING.yml](FUNDING.yml) | Bouton « Sponsor » sur tous les dépôts, vers HelloAsso |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Code de conduite commun |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Guide de contribution commun |
| [SECURITY.md](SECURITY.md) | Politique de signalement de vulnérabilités |
| [SUPPORT.md](SUPPORT.md) | Où trouver de l'aide |
| [ISSUE_TEMPLATE/](ISSUE_TEMPLATE/) | Modèles d'issues par défaut |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | Modèle de pull request par défaut |

Les fichiers communautaires placés ici (code de conduite, contribution, sécurité, modèles) s'appliquent automatiquement à tous les dépôts de l'organisation qui n'en définissent pas leur propre version.
