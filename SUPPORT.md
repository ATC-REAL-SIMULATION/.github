# Support

## Vous avez une question sur un projet ?

1. Consultez le README du dépôt concerné.
2. Cherchez dans les issues existantes, ouvertes et fermées.
3. Si vous ne trouvez pas de réponse, ouvrez une issue en utilisant le modèle « Question ».

## Vous avez une question sur l'association ou les événements ?

Contactez l'association via ses canaux de communication (réseaux sociaux, Discord de l'événement, IVAO France). Le bureau, composé de bénévoles, vous répondra dès que possible.

## Vous voulez participer à une édition d'ATC-REAL ?

Les appels à contrôleurs sont publiés avant chaque édition. Suivez les annonces de l'association et d'IVAO France.
