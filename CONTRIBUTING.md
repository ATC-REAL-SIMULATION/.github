# Contribuer

Merci de votre intérêt pour les projets d'ATC-Real Simulation. Que vous soyez contrôleur IVAO, développeur, streamer ou simple curieux, il y a plusieurs façons d'aider.

## Comment aider

### 💻 Contribuer au code

1. Ouvrez une issue pour décrire ce que vous souhaitez faire, afin d'éviter le travail en double.
2. Forkez le dépôt concerné et créez une branche depuis `main` :
   ```bash
   git checkout -b feat/ma-fonctionnalite
   ```
3. Faites des commits clairs et concis. Le préfixe [Conventional Commits](https://www.conventionalcommits.org/fr/) est apprécié (`feat:`, `fix:`, `docs:`, etc.).
4. Vérifiez que le projet se lance et que les tests passent, s'il y en a.
5. Ouvrez une pull request en remplissant le modèle proposé.

### 🐛 Signaler un bug

Utilisez le modèle « Rapport de bug » du dépôt concerné. Précisez le contexte (édition, logiciel, système, version) et les étapes pour reproduire.

### 💡 Proposer une idée

Utilisez le modèle « Proposition de fonctionnalité ». Décrivez le besoin avant la solution.

### 🎧 Participer aux événements

Les éditions d'ATC-REAL réunissent des contrôleurs IVAO en présentiel à Montpellier. Les appels à participation sont relayés sur les canaux de l'association et d'IVAO France.

### 💚 Soutenir financièrement

Salle, matériel, logistique et stream ont un coût. Vous pouvez faire un don sur HelloAsso :
https://www.helloasso.com/associations/atc-real-simulation/formulaires/1

## Règles de base

- Respectez le [code de conduite](CODE_OF_CONDUCT.md).
- Restez dans le périmètre de l'issue ou de la PR : une PR, un sujet.
- Ne commitez jamais de secrets (clés, mots de passe, tokens).
- Le français est la langue par défaut des échanges, l'anglais est bienvenu.

## Revue

Les membres de l'association relisent les pull requests. Une relecture peut prendre quelques jours, l'association étant animée par des bénévoles.
