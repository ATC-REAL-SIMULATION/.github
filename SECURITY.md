# Politique de sécurité

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans l'un des projets de l'organisation ATC-REAL-SIMULATION, **merci de ne pas ouvrir d'issue publique**.

Utilisez de préférence la fonctionnalité **« Report a vulnerability »** de l'onglet *Security* du dépôt concerné (GitHub Private Vulnerability Reporting). À défaut, contactez le bureau de l'association en privé via ses canaux de communication.

Merci d'inclure :

- une description de la vulnérabilité et de son impact potentiel ;
- les étapes pour la reproduire ;
- la version ou le commit concerné ;
- le cas échéant, une proposition de correctif.

## Engagement

L'association est animée par des bénévoles. Nous nous engageons à accuser réception de votre signalement dans les meilleurs délais, à vous tenir informé de l'avancement et à vous créditer, si vous le souhaitez, lors de la publication du correctif.

## Périmètre

Cette politique couvre les dépôts de l'organisation GitHub ATC-REAL-SIMULATION. Les services tiers utilisés par l'association (IVAO, Twitch, HelloAsso, etc.) disposent de leurs propres politiques de sécurité.
